# IT/OT network topology documentation example

Published at the owner's request as an original reference example. The Technical Documentation service page displays the logical topology and an expandable documentation register. The homepage Purdue Model section links to it.

The two 17 x 11 inch landscape sheets contain 24 identified devices and 23 numbered links. The PDF and editable Visio drawing are hosted under resources/network-topology and offered via free GitHub downloads. WebP previews are lossless conversions of the checked PDF renders. This is not a customer network or a verified as-built drawing; addressing, VLAN, physical port, model, and location fields remain TBD.

Verification: the two-page PDF was rendered and visually checked. The VSDX package, native shapes, device properties, and 46 glued connector endpoints were checked structurally; desktop Visio was unavailable, so native application rendering has not been verified. The static server requires no changes.
